# Без дыма

Помощник, чтобы бросить курить. Приложение для iPhone (PWA): ставится на главный экран через Safari,
работает без интернета, все данные хранятся только в телефоне.

Что внутри:
1. «Тянет курить»: 5 минут движения, дыхание, свои причины.
2. Дневник тяги в один тап и главные триггеры за неделю. Отдельное предупреждение про алкоголь.
3. «Чего ждать сейчас» по дню отказа.
4. Сообщения поддержки на главной (пока внутри приложения).
5. Счётчик и 25 этапов восстановления с объяснением «что это даёт».
6. Копилка и цель.
7. «Я закурил»: без стыда, общие дни и деньги сохраняются.
8. Помощь: лекарства и врач.

Тексты и цифры взяты из отчёта «Отказ от курения: научные данные» (`js/data.js`).

## Личный скин

Котик, костёр, шрифт и звуки из своей копии Stardew Valley. Это файлы игры: **в репозиторий
и на сайт не попадают** (`.gitignore`), живут только в телефоне.

1. На компьютере: `node tools/make-skin.mjs` соберёт `C:\Claude code\_assets\packs\bez-dyma-skin.json`
   из папки `C:\Claude code\_assets`. Нужен только Node 18+.
2. Перекинуть файл на телефон (Telegram «Избранное», AirDrop, iCloud).
3. В приложении: Настройки → Личный скин → Загрузить скин.

Без скина приложение рисуется своим котиком и звучит синтезом.
